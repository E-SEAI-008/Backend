TypeScript <=> C#

| TypeScript       | C#             |
| ---------------- | -------------- |
| `async function` | `async Task`   |
| `Promise<T>`     | `Task<T>`      |
| `await`          | `await`        |
| `Promise.all`    | `Task.WhenAll` |
| `Promise.race`   | `Task.WhenAny` |
| `try / catch`    | `try / catch`  |
