### SQL vs. NoSQL

| SQL (relational)            | NoSQL (MongoDB)                  |
| --------------------------- | -------------------------------- |
| Tables with rows & columns  | Collections with JSON documents  |
| Fixed structure (schema)    | Flexible structure (schema-less) |
| Data is highly linked       | Data is often embedded           |
| Examples: MySQL, PostgreSQL | Examples: MongoDB, CouchDB       |

## MongoDB Atlas Setup

1. Go to https://www.mongodb.com/atlas
2. Create an account or sign in
3. Create an **Organization** → e.g., _ESEAI-08_
4. Create a **Project** → e.g., _Node-Intro_
5. Create a **Cluster** → choose the free **M0 cluster**
6. Pick a cloud provider (AWS, GCP, or Azure) and a region
7. Create a **database user** with a password
8. Copy the **connection string**
